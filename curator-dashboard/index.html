Parsed Filename Search Help

Searches across all parsed metadata fields stored from the Filename Parser.

Chaining: Space-separated terms are ANDed. Each term can be field:value or plain text.

Examples:
anime:"Ichijyoma Mankitsu Gurashi" episode:09 — exact anime name + episode
anime:Gurashi episode:09 — partial match (anime contains "Gurashi")
Erai-raws anime:Gurashi — group name + anime name
artist:Mineori — Pixiv images by artist
108521179 — plain text searches all fields
Artist name e.g. artist:Ichijyoma Pixiv ID e.g. pixiv_id:108521179 or just 108521179 Anime name e.g. anime:Gurashi Episode e.g. episode:09 Source group e.g. group:Erai-raws Resolution e.g. resolution:1080p Date e.g. date:2022-05-14

Use the Type dropdown to filter by parse type (e.g. only Anime Screenshots). Leave it on "All Parse Types" to search everything.
